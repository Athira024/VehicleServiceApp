# AUTONEXA – Vehicle Service & Maintenance Portal

**AUTONEXA** (*"Your Car.. Our Care..."*) is a full-stack web application built with **ASP.NET Core MVC** and **Microsoft SQL Server**. It provides a streamlined platform for customers to browse vehicle service packages, book appointments, register vehicles, and track service history, while equipping administrators with a centralized control center to manage service offerings, bookings, customer directories, and feedback.

---

## Key Features

### Customer Portal
* **Account & Vehicle Registration:** Customers can create accounts and link their vehicles to their profile for streamlined servicing.
* **Service Discovery & Live Search:** Browse available maintenance and repair packages with descriptions and pricing, supported by an instant client-side search filter.
* **Appointment Booking & Emergency Rescue:** Schedule routine service appointments or request on-demand breakdown/rescue assistance.
* **Service History & Feedback:** Track past and ongoing service records and submit feedback.

### Admin Control Center
* **Centralized Dashboard:** Providing quick access to all administrative modules.
* **Service Management (CRUD):** Add new service packages, update pricing, and edit existing service descriptions.
* **Booking & Job Tracking:** Monitor incoming service requests, manage emergency dispatches, and update job statuses.
* **Customer & Vehicle Directories:** Inspect registered user accounts and linked vehicle histories.
* **Feedback Review:** View and monitor customer feedback.

---

## Tech Stack

* **Backend:** C#, ASP.NET Core MVC, ADO.NET
* **Database:** Microsoft SQL Server
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **IDE:** Visual Studio 2022
